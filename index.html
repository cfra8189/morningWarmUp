The project begins to hold everyone accountable, because everything has to be documented. A trail...

Branches in gitHub offer more control which brings clarity. Every idea shouldn't be push all at once and any given moment. It wouldn't produce the best environment. Ideas are appreciated and encouraged. We use creativity combined with skill to build and propose changes. Every change/idea must be reviewed and then approved to be pushed.

We can minimize the likelihood of frequent merge conflicts in a collaborative project by having a stable version. Keeping the clean code and reviewing with MVP in mind is vital. It creates an open, productive environment to share and discuss changes to make decisions that enhance/optimize the MVP.
